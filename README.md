# 영단어 퀴즈 — 공무원 영어

클릭만으로 푸는 영단어 퀴즈 앱. 타이핑 없이 모든 문제를 탭/클릭으로 풀 수 있어 모바일에서 빠르게 회전시킬 수 있습니다.

빌드 도구도 서버도 필요 없는 정적 사이트입니다. `index.html`을 열면 바로 동작하고, 학습 기록은 브라우저의 `localStorage`에 저장됩니다.

## 정복 모드 (코스)

단어 **5개를 한 묶음**으로 잡고, 그 묶음이 단계를 차례로 통과하게 만드는 통합 코스입니다. 개별 연습 모드가 "짧게 돌리는 연습"이라면 이쪽은 "제대로 파는 코스"입니다.

```
 미리보기  묶음 단어 훑어보기 (첫 노출)
  1단계   4지선다 — 영↔한 양방향
  2단계   문장 빈칸 — 문맥 적용
 마지막   짝 맞추기 보드 — 묶음 전체 확인
```

4지선다는 **단어마다 방향을 번갈아** 배정해 한 묶음에 영→한과 한→영이 섞이게 합니다. 한→영이 훨씬 어렵고 실전적입니다.

짝 맞추기는 한 문제에 5~6단어를 동시에 다루는 모드라 "단계"보다 **묶음의 마지막 관문**에 어울립니다. 첫 노출은 미리보기가 담당하므로 도입 보드는 두지 않습니다.

### 큐 기반 간격 배치

**같은 단어를 4단계 연속으로 물으면 직전 답이 단기기억에 남아 그냥 풀립니다.** 학습이 일어나지 않습니다. 그래서 각 단어는 "지금 몇 단계인지"를 들고 큐를 돌며, 재등장까지 **최소 3문제 간격**을 강제합니다.

```
Q1  abate    1단계        Q6  cogent   2단계
Q2  cogent   1단계        Q7  dearth   2단계
Q3  tacit    1단계        Q8  prudent  2단계
Q4  abate    2단계  ←     Q9  tacit    2단계
Q5  prudent  1단계        ...
[마지막] 짝 맞추기 보드
```

묶음 후반에는 남은 단어가 줄어 큐가 짧아지고 간격이 무너집니다. 그때는 **이미 정복한 단어를 복습 문제로 끼워 넣어** 간격을 유지합니다. 복습 문제는 정복 상태를 되돌리지 않고 숙련도에만 반영됩니다.

### 그 밖의 규칙

- **틀리면 한 단계 강등** — 다시 통과해야 올라갑니다. 모르는 단어가 자동으로 반복됩니다. (1단계에서 틀리면 더 내려갈 곳이 없으므로 같은 단계를 다시 봅니다.)
- **이미 아는 단어는 1단계를 건너뜁니다** — 숙련도 4 이상이면 문장 빈칸부터 시작합니다. 별도의 레벨 테스트 없이 개인화됩니다.
- **묶음 구성** — 같은 품사, 레벨 차이 전원 ±1 이내, 서로 뜻이 겹치지 않는 단어끼리 모읍니다. 문장 빈칸까지 진행되려면 예문이 필요하므로 후보는 260단어입니다.
- **진행 현황은 번호로만 표시** — 아직 출제될 단어를 화면에 띄우면 선택지와 대조해 정답을 골라낼 수 있습니다. 단어 이름은 **정복한 뒤에만 공개**되며, 그 공개가 보상이 됩니다.
- 같은 묶음의 단어는 서로의 오답으로 등장하지 않습니다.
- 두 단계를 모두 통과하면 숙련도 보너스를 줍니다.
- 계속 틀려도 세션이 끝없이 늘어나지 않도록 문제 수 상한이 있습니다 (묶음 크기 × 5). 상한에 걸려 일부만 정복해도 숙련도는 남아 **다음 묶음에서 이어집니다.**

### 묶음 크기별 분량

첫 학습(숙련도 0, 단계 생략 없음) 기준 실측값입니다. 표의 문제 수에 마지막 짝 맞추기 보드 1개가 더해집니다.

| 정확도 | 4단어 | 5단어 | 6단어 |
|---|---|---|---|
| 100% | 8문제 | 10문제 | 12문제 |
| 80% | — | 11문제 · 정복 5/5 | — |
| 60% | — | 24문제 · 정복 5/5 | — |

## 개별 연습 5가지 모드

| 모드 | 내용 | 출제 가능 |
|---|---|---|
| **4지선다** | 영→한 / 한→영을 번갈아 출제 | 396단어 |
| **아닌 것 고르기** | 유의어 3개 + 바꿔 쓸 수 없는 1개 | 392단어 |
| **짝 맞추기** | 5~6쌍 보드를 모두 연결 | 396단어 |
| **문장 빈칸** | 예문 속 빈칸에 알맞은 단어 | 356단어 |
| **연어 고르기** | 전치사·동사 조합 (`absent __ class`) | 18단어 |

## 오답 선택지 설계

선택지 품질이 이 앱의 핵심입니다. 랜덤으로 뽑으면 난이도가 무너지므로 다음 규칙을 적용합니다.

- 같은 품사, CEFR 레벨 차이 ±1 이내 — 레벨이 튀면 정답이 그냥 보입니다
- 정복 모드에서는 같은 묶음의 단어가 서로의 오답으로 등장하지 않습니다
- 정답과 뜻이 겹치는 단어, 정답의 유의어는 오답에서 제외 — 복수 정답 문제를 방지
- **영→한**은 반의어를 1개 의도적으로 포함 → 뜻의 경계를 정확히 아는지 검증
- **한→영·문장 빈칸**은 철자가 닮은 단어를 우선 (`impartial / implausible / impervious / imperative`)
- 문장 빈칸의 오답은 정답과 **같은 어형으로 변환**해 제시 (원형만 나열하면 정답이 드러남)
- 짝 맞추기는 5~6쌍으로 구성하고, 보드 안에 뜻이 겹치는 단어를 넣지 않아 소거법을 어렵게 만듭니다

## 학습 기록

- 단어별 숙련도 0~5 (정답 +1 / 오답 −1)
- 출제 우선순위: 숙련도가 낮은 단어와 최근 틀린 단어를 먼저 냅니다
- 오답 노트 자동 생성 — 틀린 단어만 모아 원하는 모드로 재출제
- 연속 학습일(streak)과 최근 2주 학습량 히트맵
- 짝 맞추기에서 마지막 남은 한 쌍은 소거법으로 자동 정답이 되므로 숙련도를 올리지 않습니다

## 진행 방식 — 시간 제한 없음

**어디에도 타이머가 없고 자동으로 넘어가지도 않습니다.** 정답이든 오답이든 정답·뜻·예문 번역을 충분히 본 뒤 직접 `다음 문제`를 눌러 넘어갑니다. 묶음 미리보기도 다 읽을 때까지 기다립니다.

### 이전 문제 · 다음 문제

지금까지 본 문제가 쌓여 있어 `이전 문제`로 돌아가 다시 볼 수 있습니다.

- 지난 문제는 **읽기 전용**입니다. 내가 고른 답과 정답이 그대로 표시되고 다시 답할 수 없습니다
- 따라서 **숙련도가 다시 기록되지 않습니다.** 왕복해도 기록은 그대로입니다
- 이미 클리어한 짝 맞추기 보드는 다시 풀 수 없으므로 완료 요약만 보여줍니다
- 아직 답하지 않은 문제에서는 `다음 문제`가 잠깁니다 (건너뛰기 방지)

## 단어 데이터 추가

`js/data/words.js`에 항목을 추가하면 됩니다. **채운 필드에 따라 모드가 자동으로 해금**되므로 뜻만 넣어도 바로 출제됩니다.

```js
{
  word: "abstain", pos: "v", level: "C1",
  meanings: ["삼가다", "기권하다"],              // 4지선다 · 짝 맞추기
  syn: ["refrain", "forgo", "withhold"],        // 아닌 것 고르기 (3개 이상)
  ant: ["indulge"],                             // 오답 품질 향상
  ex: [{ s: "Three members chose to {{}} from the vote.",
         f: "abstain",
         ko: "세 명의 위원이 투표에서 기권하기로 했다." }],   // 문장 빈칸
  col: [{ p: "abstain {{}} alcohol", a: "from",
          pool: "prep", note: "abstain from ~ : ~을 삼가다" }] // 연어
}
```

- `pos` — `v` / `n` / `adj` / `adv` / `phr`(구·표현)
- `level` — `B1` / `B2` / `C1` / `C2`
- `ex[].f` — 문장에 실제로 들어갈 어형 (`corroborated`처럼 변화형 가능)
- `col[].pool` — `prep`, `verb`(고정 풀에서 오답 추출), `auto`(같은 품사 단어에서 추출), 또는 `opts`로 직접 지정

현재 수능 보카 A 섹션 396단어 (B1 77 / B2 147 / C1 144 / C2 28). 구·표현(pos:`phr`) 36개 포함.

## 실행

```bash
# 저장소 루트에서
python3 -m http.server 8000
# → http://localhost:8000
```

`file://`로 직접 열어도 동작하지만, 서비스 워커(오프라인 기능)는 `http` 환경에서만 등록됩니다.

## 배포

`main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다 (`.github/workflows/pages.yml`). 저장소 **Settings → Pages → Source**를 `GitHub Actions`로 설정해야 합니다.
