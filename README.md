# 영단어 퀴즈 — 공무원 영어

클릭만으로 푸는 영단어 퀴즈 앱. 타이핑 없이 모든 문제를 탭/클릭으로 풀 수 있어 모바일에서 빠르게 회전시킬 수 있습니다.

빌드 도구도 서버도 필요 없는 정적 사이트입니다. `index.html`을 열면 바로 동작하고, 학습 기록은 브라우저의 `localStorage`에 저장됩니다.

## 정복 모드 (코스)

**세트 → 챕터(20단어) → 드릴** 구조입니다. 한 챕터를 골라 20단어를 여러 형식으로 돌려 푸는 통합 코스입니다. 개별 연습이 "한 형식만 짧게 돌리는 연습"이라면 이쪽은 "한 챕터를 제대로 파는 코스"입니다.

```
 미리보기  챕터 20단어를 뜻과 함께 훑어보기
  드릴    1단계  4지선다 (영↔한)              — 전 단어
          2단계  아닌 것 고르기                — 유의어 3개 이상인 단어
          3단계  문장 빈칸                     — 예문이 있는 단어
          4단계  연어 고르기                   — 연어가 있는 단어
  보드    짝 맞추기 4~5쌍 × 4개 보드로 마무리
  결과
```

각 단어는 **데이터가 허용하는 만큼의 단계만** 밟습니다. 예문이 없는 단어는 3단계를 건너뛰고, 연어가 없으면 4단계가 없습니다. 그래서 챕터마다 문제 수가 조금씩 다릅니다.

4지선다는 **단어마다 방향을 번갈아** 배정해 한 챕터에 영→한과 한→영이 섞이게 합니다. 한→영이 훨씬 어렵고 실전적입니다.

짝 맞추기는 한 문제에 4~5쌍을 동시에 다루는 모드라 "단계"보다 **챕터의 마지막 관문**에 어울립니다. 첫 노출은 미리보기가 담당하므로 도입 보드는 두지 않습니다.

### 큐 기반 간격 배치

**같은 단어를 여러 단계 연속으로 물으면 직전 답이 단기기억에 남아 그냥 풀립니다.** 학습이 일어나지 않습니다. 그래서 각 단어는 "지금 몇 단계인지"를 들고 큐를 돌며, 재등장까지 **최소 3문제 간격**을 강제합니다.

```
Q1  fable      1단계        Q6  fabric     2단계
Q2  fabric     1단계        Q7  fabricate  2단계
Q3  fabricate  1단계        Q8  fabulous   2단계
Q4  fable      2단계  ←     Q9  fable      3단계
Q5  fabulous   1단계        ...
[마지막] 짝 맞추기 보드 4개
```

### 그 밖의 규칙

- **강등 없음** — 틀려도 다음 문제로 넘어갑니다. 틀린 단어는 오답 노트에 쌓여 따로 복습합니다.
- **건너뜀 없음** — 이미 아는 단어라고 단계를 생략하지 않습니다. 모든 단어가 가능한 단계를 전부 밟습니다.
- **자유 이동** — `이전 문제` / `다음 문제`로 왕복할 수 있습니다.
- **챕터 구성** — 세트 안에서 20단어씩 순서대로 끊습니다. 마지막 챕터만 20개보다 적을 수 있습니다.
- 같은 챕터의 단어는 서로의 오답으로 등장하지 않습니다.
- **이어풀기** — 중단해도 그 챕터를 이어서 풉니다. 챕터 목록에는 내가 풀어본 챕터에만 `· 오답 N`이 빨갛게 붙습니다 (아직 열지 않은 챕터에 다른 모드에서 틀린 단어가 새는 것을 막습니다).

### 오답 복습 세션

오답 노트의 단어만 모아 정복 모드와 같은 방식(미리보기 → 드릴 → 보드)으로 다시 출제합니다. 오답은 여러 세트에 걸쳐 있으므로 이 세션만 **세트 경계를 무시**합니다. 짝 맞추기도 대상 단어가 빠짐없이 등장하는 복습 전용 보드를 씁니다.

## 개별 연습 5가지 모드

형식을 고른 뒤 세트(A~F)를 고르면 **그 세트를 통째로** 풉니다. 진행 바를 드래그해 원하는 문제로 바로 이동할 수 있습니다.

| 모드 | 내용 | 출제 가능 |
|---|---|---|
| **4지선다** | 영→한 / 한→영을 번갈아 출제 | 1,889단어 |
| **아닌 것 고르기** | 유의어 3개 + 바꿔 쓸 수 없는 1개 | 1,842단어 |
| **짝 맞추기** | 5~6쌍 보드를 모두 연결 | 1,889단어 |
| **문장 빈칸** | 예문 속 빈칸에 알맞은 단어 | 1,719단어 |
| **연어 고르기** | 전치사·동사 조합 (`absent __ class`) | 62단어 |

## 오답 선택지 설계

선택지 품질이 이 앱의 핵심입니다. 랜덤으로 뽑으면 난이도가 무너지므로 다음 규칙을 적용합니다.

- 같은 품사, CEFR 레벨 차이 ±1 이내 — 레벨이 튀면 정답이 그냥 보입니다
- 정복 모드에서는 같은 챕터의 단어가 서로의 오답으로 등장하지 않습니다
- 정답과 뜻이 겹치는 단어, 정답의 유의어는 오답에서 제외 — 복수 정답 문제를 방지
- **영→한**은 반의어를 1개 의도적으로 포함 → 뜻의 경계를 정확히 아는지 검증
- **한→영·문장 빈칸**은 철자가 닮은 단어를 우선 (`impartial / implausible / impervious / imperative`)
- 문장 빈칸의 오답은 정답과 **같은 어형으로 변환**해 제시 (원형만 나열하면 정답이 드러남)
- 짝 맞추기는 보드 안에 뜻이 겹치는 단어를 넣지 않아 소거법을 어렵게 만듭니다

## 학습 기록

숙련도(0~5) 시스템은 없앴습니다. "몇 점인지"보다 **틀린 단어를 몇 번 다시 틀렸는지**가 학습에 훨씬 유용하기 때문입니다.

### 오답 노트 3차 구조

단어마다 "도달한 최고 차수"(`wn`, 0~3) 하나만 저장하고, 목록은 그 값으로 가릅니다.

```
1차 목록 = wn ≥ 1     ← 2차·3차 단어도 모두 포함
2차 목록 = wn ≥ 2     ← 3차 단어도 포함
3차 목록 = wn ≥ 3
```

승급은 **"복습에서도 또 틀렸다"**만 셉니다.

| 상황 | 결과 |
|---|---|
| 일반 연습에서 틀림 | 아직 없으면 1차. 이미 1차 이상이면 그대로 |
| 1차 복습에서 틀림 | 2차 |
| 2차 복습에서 틀림 | 3차 (최고) |
| 맞힘 | 아무 일도 없음 — 목록에서 사라지지 않습니다 |

맞혀서 저절로 빠지는 길은 없습니다. 나가는 길은 둘입니다 — 직접 `✕`로 빼거나, 북마크로 넣은 단어의 **북마크를 해제**하는 것입니다.

### 그 밖에 남는 기록

- 홈의 진행률 — 한 번이라도 출제된 단어(`seen > 0`) 수 / 전체 단어 수
- 연속 학습일(streak)과 최근 2주 학습량 히트맵
- ★ 저장(북마크) — 아무 단어나 따로 모아 둘 수 있고, 저장하면 오답 노트 1차에도 들어갑니다
- 단어장 필터 — 전체 / 미학습 / 학습함 / 오답 / ★ 저장 × 레벨(B1~C2)
- 짝 맞추기에서 마지막 남은 한 쌍은 소거법으로 자동 정답이 되므로 기록에 반영하지 않습니다

### 기기 간 동기화

로그인하면 폰과 PC의 기록이 합쳐집니다 (`js/sync.js` · Firebase Auth + Firestore).

- **localStorage가 정답입니다.** 서버는 백업·공유 채널일 뿐이라 오프라인이어도 앱은 그대로 동작하고 동기화만 멈춥니다
- 매 문제 전송하지 않고 60초 디바운스 + 화면 이탈 시 강제 flush로 묶습니다 (Firestore 쓰기 과금이 25배 차이)
- 덮어쓰지 않고 **단어별로 최신을 택해 합칩니다** — 폰과 PC에서 다른 단어를 공부해도 양쪽이 남습니다
- 이어풀기 스냅샷은 동기화하지 않습니다 (기기별로 다른 것이 자연스러움)

## 진행 방식 — 시간 제한 없음

**어디에도 타이머가 없고 자동으로 넘어가지도 않습니다.** 정답이든 오답이든 정답·뜻·예문 번역을 충분히 본 뒤 직접 `다음 문제`를 눌러 넘어갑니다. 챕터 미리보기도 다 읽을 때까지 기다립니다.

### 이전 문제 · 다음 문제

지금까지 본 문제가 쌓여 있어 `이전 문제`로 돌아가 다시 볼 수 있습니다.

- 지난 문제는 **읽기 전용**입니다. 내가 고른 답과 정답이 그대로 표시되고 다시 답할 수 없습니다
- 따라서 **기록이 다시 쌓이지 않습니다.** 왕복해도 기록은 그대로입니다
- 이미 클리어한 짝 맞추기 보드는 다시 풀 수 없으므로 완료 요약만 보여줍니다
- 아직 답하지 않은 문제에서는 `다음 문제`가 잠깁니다 (건너뛰기 방지)

## 단어 데이터 추가

### 기존 세트에 단어 추가

해당 세트 파일(`js/data/words.js`, `words-b.js` … `words-f.js`)에 항목을 추가하면 됩니다. **채운 필드에 따라 모드가 자동으로 해금**되므로 뜻만 넣어도 바로 출제됩니다.

```js
{
  word: "abstain", pron: "업스테인", pos: "v", level: "C1",
  meanings: ["삼가다", "기권하다"],              // 4지선다 · 짝 맞추기
  syn: ["refrain", "forgo", "withhold"],        // 아닌 것 고르기 (3개 이상)
  ant: ["indulge"],                             // 오답 품질 향상
  ex: [{ s: "Three members chose to {{}} from the vote.",
         f: "abstain",
         ko: "세 명의 위원이 투표에서 기권하기로 했다." }],   // 문장 빈칸
  col: [{ p: "abstain {{}} alcohol", a: "from",
          pool: "prep", note: "abstain from ~ : ~을 삼가다" }] // 연어
}
```

- `pos` — `v` / `n` / `adj` / `adv` / `phr`(구·표현)
- `level` — `B1` / `B2` / `C1` / `C2`
- `meanings` — 대표 2개까지. 첫 뜻에 괄호 설명을 넣지 않습니다 (선택지에 그대로 찍힘)
- `ex[].f` — 문장에 실제로 들어갈 어형. **규칙 변화만** 씁니다. 불규칙이면 오답이 원형으로 남아 뜻을 몰라도 정답이 보입니다
- `col[].pool` — `prep`, `verb`(고정 풀에서 오답 추출), `auto`(같은 품사 단어에서 추출), 또는 `opts`로 직접 지정

`syn`에 쓴 단어가 표제어(VOCAB)가 아니면 한국어 뜻을 사전에 등록해야 '아닌 것 고르기' 선택지 아래에 뜻이 찍힙니다. 세트 파일 맨 아래 또는 `js/data/gloss.js`에 넣습니다. 값은 **쉼표로 이은 문자열**이고 뜻은 2개까지입니다 (선택지 아래 한 줄에 들어가야 함).

```js
Object.assign(window.GLOSS, {
  "abhor": "혐오하다, 증오하다",
  "acclimate to": "~에 적응하다"
});
```

> ⚠️ **`window.GLOSS = {...}` 로 재대입하면 다른 세트의 사전이 통째로 사라집니다.** 반드시 `Object.assign`으로 병합하세요. `GLOSS`·`PRON` 조회는 `s.toLowerCase()`로 하므로 **키는 반드시 소문자, 앞뒤 공백 없이** 씁니다 (`"of the Middle Ages"` ✗ / `"of the middle ages"` ✓). 같은 문제의 유의어 둘이 **뜻 문자열까지 같아지면** 복수 정답처럼 보이므로 서로 다르게 씁니다.

### 새 세트 추가
